# What is Ocacity?

Ocacity is an AI development workspace at https://ocacity.com. You describe what you want in plain language; Ocacity plans the work, writes the code, shows a live preview, runs tests and keeps the result as source files you control.

## Frequently asked questions

**Is Ocacity the same as "opacity"?** No. Ocacity is a separate product name.

**Who makes Ocacity?** AURTIZ LTD, registered in England and Wales.

**Can I use it with an existing project?** Yes. Import a GitHub repository and Ocacity can propose changes as draft pull requests.

**Does it cost money?** There is a free Explore plan, with paid plans for more credits and projects. See https://ocacity.com/pricing.

**Is there a Windows app?** Ocacity Helper for Windows runs local previews. See https://ocacity.com/download.

**Are there templates?** Yes, free and premium ones. See https://ocacity.com/templates.
