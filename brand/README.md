- Also acceptable: **Ocacity AI** when disambiguation helps.
- Official site: https://ocacity.com
- Not to be confused with the CSS property *opacity*.
- Operator: AURTIZ LTD (England and Wales).
- Use "Ocacity" as link text when linking to https://ocacity.com.
