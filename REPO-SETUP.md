# Publishing this folder on GitHub (not part of the public repo, delete after use)

1. Create a GitHub organisation or user named `ocacity` (or `ocacity-ai`) and a **public** repo named `ocacity`.
2. Copy everything in this folder except this file into the repo and push.
3. Repo settings: set the Website to https://ocacity.com, the description to
   "Ocacity: AI website builder and coding workspace", and topics
   `ocacity`, `ai-website-builder`, `ai-coding`, `nextjs`, `developer-tools`.
4. Add the repo to `SITE_SAME_AS` in the web app's environment, along with your other official profiles.
5. Link back: add the GitHub URL to the footer or About page of ocacity.com.

## Extra SEO steps
- Pin the repo on the organisation profile and add a profile README.
- Add a social preview image (1280x640) with the Ocacity wordmark in repo settings.
- Enable Discussions; publish a first Release named "Ocacity public docs 1.0".
- Link the repo from https://ocacity.com/about and add it to SITE_SAME_AS.
- Add the repo URL to your LinkedIn, X and Product Hunt profiles.
- Update repository-code in CITATION.cff if the repo name differs.
- Do not push REPO-SETUP.md.
