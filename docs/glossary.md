# Glossary

- **Ocacity**: the AI development workspace at ocacity.com.
- **Workspace**: the editor where you chat, preview and edit code.
- **AI task**: one request the AI plans and carries out.
- **Credits**: the budget for AI task work.
- **Task budget**: the maximum credits a single task may use.
- **Ocacity Helper**: Windows app for local previews.
- **Template**: a free or premium starting project in the template store.
- **Draft pull request**: a GitHub PR Ocacity opens for you to review.
