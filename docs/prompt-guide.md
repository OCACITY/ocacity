# How to write a good website prompt for Ocacity

Clear prompts get better first builds. Include:

1. **Purpose**: what the site is for and who visits it.
2. **Pages and sections**: for example Home, Menu, About, Contact.
3. **Style**: tone, colours, and sites whose feel you like.
4. **Content**: real headings, offers, and contact details if you have them.
5. **Constraints**: framework (Next.js, Angular, Vite), accessibility needs, languages.

## Example

> Build a one-page site for a bicycle repair shop in Leeds. Sections: hero with booking button, services with prices, opening hours, map, contact form. Calm, clean style, white background, one green accent. Next.js.

## Tips
- Start with one focused task, then iterate.
- Ask for one change at a time.
- Say what must not change.
