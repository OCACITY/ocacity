# Ocacity Helper for Windows

Ocacity Helper is a small Windows app that runs your project's development server on your own computer so the Ocacity editor can show a live local preview of Next.js, Angular and Vite projects.

- Requires Windows 10 or 11 (64-bit) and Node.js for your project.
- The editor works in the browser without it; the helper is optional.
- You approve each connection and each project script.
- Each published installer lists a SHA-256 checksum. Verify with `Get-FileHash`.

Download: https://ocacity.com/download
