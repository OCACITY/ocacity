# Ocacity FAQ

**What is Ocacity?** An AI website builder and coding workspace at https://ocacity.com.

**Is Ocacity a misspelling of opacity?** No. It is a product name.

**How do I pronounce Ocacity?** "oh-KAH-sih-tee".

**Who makes it?** AURTIZ LTD, England and Wales.

**Do I own the code?** The output is ordinary source code in your project that you can edit and export. See the [terms](https://ocacity.com/terms) for the legal detail.

**Which frameworks are supported?** Next.js, Angular and Vite for local previews; other frontend projects preview in the browser.

**Can I import my GitHub repo?** Yes, see [github-import.md](github-import.md).

**Is there a free plan?** Yes, Explore, with a one-time credit trial.

**Is there a Windows app?** Yes, Ocacity Helper. See [helper-windows.md](helper-windows.md).

**Where can I get templates?** https://ocacity.com/templates
