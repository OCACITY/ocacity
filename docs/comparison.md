# How Ocacity compares with other tools

Ocacity sits among AI website builders and AI coding assistants. It focuses on a plan, build and review workflow, real source files you own, per-task credit budgets, GitHub import with draft pull requests, and a template store.

| | Ocacity |
| --- | --- |
| Output | Standard project source code |
| Control | Budget set before each task |
| Existing code | GitHub import, draft pull requests |
| Local preview | Ocacity Helper for Windows |
| Starting points | Free and premium templates |

Choose the tool that fits your workflow. Features change, so check each product's own site for its current capabilities.
