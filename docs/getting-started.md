# Getting started with Ocacity

Ocacity is an AI website builder and coding workspace at https://ocacity.com.

## 1. Create an account
Go to https://ocacity.com/sign-up. Verify your email with the five-digit code we send you. The free Explore plan includes a one-time trial of AI task credits.

## 2. Start a project
Describe what you want, for example: "A landing page for a coffee roastery with a menu, a story section and a contact form." Or pick a starting point from the [template store](https://ocacity.com/templates).

## 3. Set a budget
Choose a maximum credit budget before the task begins. Reaching it never triggers an automatic charge.

## 4. Review the work
Ocacity plans, implements and reviews. Watch the live preview, read the code, and ask for changes in plain language.

## 5. Keep going
Edit the code directly, run tests, import a GitHub repository, or open draft pull requests.
