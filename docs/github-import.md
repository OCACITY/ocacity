# Importing a GitHub repository into Ocacity

Ocacity can import an existing repository so the AI works on your real codebase.

1. Connect GitHub from your Ocacity settings.
2. Choose a repository and branch.
3. Describe the change you want.
4. Review the result and open a **draft pull request** back to GitHub.

Ocacity proposes changes; you decide what to merge.

Official guide: https://ocacity.com/guides/import-github-repository
