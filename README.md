> **Ocacity** (also written *Ocacity AI*, pronounced "oh-KAH-sih-tee") is a product name for an AI development workspace at [ocacity.com](https://ocacity.com). It is **not** a misspelling of "opacity". If you searched for the CSS property, see [MDN: opacity](https://developer.mozilla.org/en-US/docs/Web/CSS/opacity).

## What is Ocacity?

Ocacity is an **AI website builder** and **AI coding workspace**. You describe a website, web app or code change in plain language. Ocacity plans the task, writes real source code, shows a live preview, runs tests and keeps everything as files you own and can edit.

It is aimed at founders, designers, freelancers, agencies and developers who want to go from idea to working site faster, without giving up control of the code.

## Features

| Capability | What it means |
| --- | --- |
| Plan, build, review | The AI plans a task, implements it, then reviews the result, with a clear budget per task. |
| Real source code | Output is standard Next.js, Angular or Vite project code, not a locked-in format. |
| Live preview | See the site in the browser as it changes; run previews locally with Ocacity Helper on Windows. |
| Tests | Runs browser-based JavaScript tests and reports results. |
| GitHub import | Import a repository and get changes back as draft pull requests. |
| Template store | Start from free or premium templates for storefronts, dashboards, portfolios, landing pages and docs. |
| Credit budgets | Set a maximum credit budget before each AI task. No automatic usage charges. |
| CLI | Run tasks from the terminal with the Ocacity CLI. |

## Get started

1. Open [ocacity.com](https://ocacity.com) and [sign up](https://ocacity.com/sign-up) for the free Explore plan.
2. Describe what you want to build, or pick a [template](https://ocacity.com/templates).
3. Review the plan, watch the preview, and edit the code.
4. Optional: [download Ocacity Helper for Windows](https://ocacity.com/download) for local previews.
