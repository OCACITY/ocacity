# Contributing to Ocacity's public resources

Thanks for helping. This repository holds public documentation, examples and community resources for [Ocacity](https://ocacity.com).

- Open an issue to report a documentation error or suggest an example.
- Open a pull request for small fixes. Keep changes focused, and write "Ocacity" with that spelling.
- Do not include secrets, personal data or private project code in issues or pull requests.
- For product support, use the contact options on https://ocacity.com.
